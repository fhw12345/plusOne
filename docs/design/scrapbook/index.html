中文 — bilingual pressure-test

6 pages · 简体 + 1 繁體

平行的中文版本，用来压力测试字体搭配。

v2 修订 — 可读性优先。 v1 把正文和标题都用手写体 (Ma Shan Zheng) — 用户反馈说太花、看不清。v2 已修：正文标题全部改为 Noto Serif SC 印刷体，手写体只保留在小注释 (`.annot` / `.margin-note` / `.signature`)。纸张更浅，纸纹与胶带透明度降低。证明截图见 screenshots-zh-v2/。详细取舍见 BILINGUAL-NOTES.md §0。

v3 加固 — 小注释也要看清。 v2 留了个软规则：`.annot` / `.margin-note` 还可以用手写中文「短片段」。实际内容一上去就破功 — 用户拎出四个串「面屋彩未在 12 个不同的帖子里出现 / ★ / ↓ / 我在做什么 / →」全都糊。v3 已修：`.annot` / `.margin-note` 强制 Noto Serif SC 16-17px 全墨；手写中文只剩 `.signature` (≤6 字) 和 `.doodle` (装饰非文字) 两个槽；★ ↓ → 等装饰字符全部包进 `.glyph` 走 Segoe UI Symbol 18px。还修了一个 cascade bug：之前 Latin 手写 bridge 把 CJK 拉回 Liu Jian Mao Cao。证明截图见 screenshots-zh-v3/。详细见 BILINGUAL-NOTES.md §0.1。
