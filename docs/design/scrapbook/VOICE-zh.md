# Plus One — Scrapbook Voice 中文版

Companion to `VOICE.md`. Same constraints, same register, *written in
Chinese* — not translated from English. The agent is hidden. The voice
is a friend texting you while doing the work, in casual, lowercase-feel
Chinese.

> Translation philosophy: don't translate phrases, translate *register*.
> "asking around on reddit" → "去 reddit 上问问看" — not
> 「在Reddit上询问相关人员」which is the AI-flavored register we are
> trying to escape. Keep Latin tokens (`reddit`, `小红书`, `JapanTravel`,
> `Tokyo`, `google places`) where a Chinese-speaking traveler would
> naturally keep them. Half-width punctuation `,` `.` works inside
> casual messages; full-width `，` `。` is for the printed report body.

---

## Voice register cheat-sheet 中文

| Trait | Yes | No |
|-------|-----|-----|
| 人称 | 第一人称「我」「让我」 | 「系统」「本应用」「我们的智能助手」 |
| 句式 | 短句、口语、像微信 | 长句、书面语、定语从句套娃 |
| 时态 | 进行时 / 正在 | 「将要」「已经完成」 |
| 调性 | 好奇、稍带玩笑、像朋友 | 热情、销售感、过度道歉 |
| 标点 | 半角混排（朋友聊天感） | 严格 GB/T 全角（生硬） |
| 表情 | 不用 emoji。`★ → …` 偶尔在红色批注里出现 | 🎉 🍜 ✨ |
| Latin 词 | 保留 reddit / 小红书 / google places / tonkotsu / 拉面 这些自然混入的词 | 翻成「红迪」「谷歌地点」 |

## SSE 事件 → 中文文案

每个事件至少 2-3 个候选句，前端轮换显示。批注（红色批注栏）选用。

### `started`
| 候选 | 批注？ |
|------|-------|
| `开干。咖啡在手。` | — |
| `好，开始看 {destination}。` | — |
| `让我看看 {destination} 有什么。` | — |

### `iteration_start`
| 第 N 轮 | 候选 |
|---------|------|
| 1 | `先去 reddit 上问问看。这边人挺多的，得过滤一下才能听见安静的那些。` |
| 2 | `再走一轮 — 有个名字反复出现，想确认一下。` |
| 3 | `往下挖一层。把信号混乱的那几个再看看。` |
| 4 | `最后一轮，把零碎线索串起来。` |

### `producer`
| 源 | 候选 | 可选批注 |
|----|------|----------|
| reddit | `从 r/{subreddit} 拉到 {n} 条，开始读。` | `主要是近半年的 ★` |
| reddit | `reddit 这边目前 12 个名字。重复出现的我标一下。` | — |
| xhs    | `现在去 小红书 查同样的名字，对一下。` | — |
| xhs    | `小红书有 {n} 条提到 {place}。那边人比较安静，信息更有用。` | `本地人才会去 ←` |
| places | `让 google places 帮忙确认地址和营业时间。` | — |

### `joiner`
| 情况 | 候选 |
|------|------|
| 多源重合健康 | `有几个出现了两次 — 保留这些。{n_out} 个对得上。` |
| 单点强烈推荐 | `{place} 在 {k} 个不同的帖子里都被提到。这个是强 yes。` |
| 发现分歧 | `两边对 {place} 的看法对不上。有意思 — 我再多看一轮，看看哪边说得对。` |
| 信号偏弱 | `只有 {n_out} 个通过了交叉验证。剩下的都是孤证。` |

### `controller`
| 决定 | 候选 |
|------|------|
| 继续深挖 | `想在下结论前对 {place} 再了解一点。再走一轮。` |
| 继续补缺 | `安静的点还不够 — 让我再找一下。` |
| 停止整理 | `把这些串起来写给你。` |
| 触顶停止 | `差不多就到这了 — 用现有的写一份。` |

### `cycle_complete`
| 候选 |
|------|
| `写完了。给你铺开看。` |
| `好，差不多了。整理一下。` |

### `trip_complete` (sticky-note)
| 候选 |
|------|
| `好了 — 钉在最上面了。` |
| `搞定。左边那些卡片，自己翻。` |

### `cycle_aborted` *(critical — stay in voice)*
| 原因 | 候选 |
|------|------|
| Maestro / LLM 不可用 | `撞墙了 — 笔记应用没回我。等一下再试？` |
| 没有候选结果 | `{destination} 这边没找到什么像样的。要么是太冷门，要么是我得换个角度问。要不你再说细一点？` |
| 校验失败 | `拉到的东西看着不太对 — 不想给你写半成品。再来一次？` |
| 未知 | `中途断了一下。不是你的错。再试一次？` |

### Heartbeat / 静默等待（前端兜底，3s 没新事件时）
| 候选 |
|------|
| `还在读…` |
| `…等一下，这帖子有点密。` |
| `给我一会儿。` |

## 地点卡片定论 (verdict 文案)

页面右下角红字 `.verdict`。可用短语：

| 类别 | 允许的短语 |
|------|-----------|
| 本地宝 (high consensus) | `去。` · `就这家 ★` · `值得绕路。` |
| 一起去 (适合一群人) | `带上大家。` · `你们都会喜欢。` |
| 个人定制 | `给 {名字}。`（如 `给雯雯。`） |
| 旅游陷阱 | `跳过。` · `不值得。` · `换 {alt} 吧 →` |
| 有争议 | `两面之词 — 自己看。` (仅票据上用) |

## "switch to printed" 切换器

| 状态 | 按钮文案 |
|------|----------|
| 默认（手写）| `换成打印体` |
| 已是打印体 | `换回手写` |

注：按钮在英文版是 `switch to printed`，对应的 typewriter 字号 10px
letter-spacing 0.2em — 中文用 `换成打印体` 只有 5 个汉字，太短显得空。
解决方案：用 `特殊·字体 · 换成打印体` 这种带前缀的形式，让按钮宽度
比较稳定。或者直接保留英文按钮（一些中文 SaaS 也这样做）。
*这是 BILINGUAL-NOTES.md 里需要决定的事项之一。*

## 5 句禁用语 (在 review 里抓)

1. `提交中…` (改成 `发了，等一下`)
2. `加载中…` (改成 `…还在读` 或者留空)
3. `AI 驱动` / `智能` 任何形式 (这是反例的核心)
4. `运行中` / `已完成` / `已中止` 作为状态徽章名词
5. 任何以 `本系统` / `本平台` / `我们的` 开头的句子
